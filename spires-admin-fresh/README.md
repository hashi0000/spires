# Spires admin (`spires-admin-fresh`)

Internal office app for Spires Taxis (React / TypeScript). Hosted with Firebase Hosting via the monorepo root `firebase.json`. Do **not** deploy the marketing site with Firebase Hosting.

## Docs

- Monorepo index: [`../docs/README.md`](../docs/README.md)
- Bookings architecture: [`../docs/admin/BOOKINGS_SYSTEM.md`](../docs/admin/BOOKINGS_SYSTEM.md)
- Customer-facing policy: [`../docs/policies/README.md`](../docs/policies/README.md)
- Share admin brief: [`../docs/share/ADMIN_AUDIT.md`](../docs/share/ADMIN_AUDIT.md)

## Local development

From this folder, use the package scripts in `package.json` (install, start, build). Point Firebase config at the `spires-taxis` project used by Functions and the customer app.
