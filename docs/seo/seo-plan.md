## IMPLEMENTATION NOTES

- All pages should follow the existing site structure (header, footer, CSS)
- Each page should have 400-700 words of natural, helpful content
- Internal links should connect related pages (e.g., Heathrow ↔ Gatwick, Oxford taxis ↔ Airport transfers)
- All pages should link to booking/contact page or Customer Portal
- Use existing pricing information only (do not invent new prices)
- Focus on real coverage areas: Oxford, Abingdon, Bicester, Kidlington, Summertown, Headington
